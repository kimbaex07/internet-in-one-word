## Entry

**Doomscroll**

The endless scroll is what the whole internet has become: feeds, headlines, and outrage, forever one thumb-flick away from stopping and never stopping. It is funny because it is true, and surprising because it is not the first obvious word that comes to mind — yet once you hear it, no other word fits quite as well.

## How to run

```sh
MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=./out python3 main.py
```

This writes `Doomscroll` to `out/entry.txt` (10 characters, no trailing newline).
